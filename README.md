## LibraryGarden

### 프로젝트소개 🌳
지식의 씨앗을 심고 가꾸는, 모두를 위한 정원			
Library Garden은 도서관 시스템에 ‘정원’이라는 따뜻한 개념을 더한 웹 플랫폼입니다.			
팀명인 Seed Story처럼, 사용자가 희망하는 도서를 신청하면 관리자가 그 요청을 검토하고 반영하여 마치 정원에 씨앗을 심듯 새로운 지식을 심어줍니다.			
그 씨앗은 대출과 예약 기능을 통해 다시 사용자에게 돌아가고, 지식이 열매 맺는 순환의 경험을 제공합니다.			
"사용자 중심의 UI/UX, 도서 정보 자동 연동, 실시간 캘린더 예약 등 다양한 기능이 유기적으로 연결되어, 단순한 대출 시스템이 아닌 ‘함께 만들어가는 디지털 지식 
정원’이라는 새로운 경험을 제안합니다."			
관리자와 사용자가 함께 콘텐츠를 만들어가며 지식이 확장되고 순환하는 플랫폼, 그것이 바로 Library Garden입니다.

### 주요기능
일반 사용자가 희망도서를 직접 신청할 수 있고, 신청 내역 및 처리 결과를 실시간으로 확인할 수 있음			
도서관 운영에 사용자 의견을 반영하여 참여형 지식 플랫폼 구현			
FullCalendar를 활용한 직관적인 달력 UI로 도서 예약 가능			
연장 여부, 연체 상태 등도 실시간으로 반영되어 편리한 도서 관리 가능			
도서 검색 시 알라딘 API를 통해 책 제목, 표지, 출판사 등 자동 불러오기			
관리자/사용자의 입력 편의성 향상 및 오류 방지			
로그인 시 역할(Role)에 따라 UI 및 기능 자동 분기			
사용자: 대출·예약·희망도서 신청			
관리자: 도서 등록, 결재 관리, 회원 관리 등 운영 중심 기능 제공
